# 투자 포트폴리오 화면 개편 계획

- 작성일: 2026-10-29
- 상태: 화면 구현 및 회귀 테스트 완료
- 대상: `src/components/InvestmentTab.tsx`

## 1. 개편 목표

현재 투자 화면의 세로 길이를 줄이고, 전체 자산과 보유 종목을 빠르게 비교할 수 있도록 구성한다.

- 전체 자산은 국내·해외를 합산한 원화 금액으로 한 번에 보여준다.
- 국내 주식과 해외 주식은 탭으로 나누어 선택한 영역만 표시한다.
- 종목별 카드를 표로 교체한다.
- 일반적인 도움말과 계산 설명은 버튼을 통해 팝업에서 확인한다.
- 모바일에서도 표의 주요 컬럼을 유지하고 좌우 스크롤을 지원한다.

## 2. 전체 화면 순서

1. 제목 및 종목 추가 버튼
2. 조회 월, 이번 달 이동, 시세 새로고침, 계산 기준 도움말
3. 전체 자산 통합 요약
4. 적용 환율과 기준 시각
5. 국내 주식 / 해외 주식 탭
6. 선택한 시장의 요약 한 줄
7. 보유 종목 표
8. 페이지 이동

```text
투자 포트폴리오                              [+ 종목 추가]
[조회 월 ▾] [이번 달]               [새로고침] [계산 기준 ⓘ]

┌ 전체 자산 · 원화 ──────────────────────────────────┐
│ 총 매수 원금          총 평가금액          총 누적 수익률 │
│ 전월 대비             전월 대비             전월 대비 │
└──────────────────────────────────────────────────┘
적용 환율 · 기준 시각

[국내 주식 8] [해외 주식 5]
매수 ○○원 · 평가 ○○원 · 수익률 ○○%

종목           평가금액      수량      원금      단가      수익률
삼성전자         …           …         …         …          …
TIGER 미국S&P500  …           …         …         …          …
────────────────────────────────────────────────────
                         [이전] 1 / 2 [다음]
```

## 3. 전체 자산 통합 요약

### 표시 항목

- 총 매수 원금
- 현재 총 평가금액
- 총 누적 수익률
- 각 항목의 전월 대비 변화

### 표시 방식

- 국내·해외 전체 보유 종목을 합산한다.
- 해외 자산은 조회한 USD/KRW 환율을 적용해 원화로 환산한다.
- 국내·해외 탭이나 종목 목록의 페이지를 전환해도 통합 요약은 전체 자산 기준을 유지한다.
- PC에서는 세 항목을 하나의 패널 안에 나란히 배치한다.
- 모바일에서는 총 평가금액을 가장 크게 표시하고, 원금과 수익률을 그 아래 나란히 배치한다.
- 전월 대비 금액은 `+○○원`, 수익률 변화는 `+○○%p`로 간결하게 표시한다.
- 전월의 실제 금액과 상세 계산 설명은 요약 상세 팝업에 표시한다.
- 이번 개편은 레이아웃 변경이며, 기존 통합 합산·전월 비교 계산 방식을 유지한다.

## 4. 국내·해외 주식 탭

- 탭 이름: `국내 주식 N` / `해외 주식 N`
- 숫자는 선택한 조회 월의 해당 시장 보유 종목 수다.
- 선택한 탭의 요약과 종목 목록만 표시한다.
- 탭 아래 요약은 매수 원금·평가금액·수익률을 한 줄로 배치한다.
- 국내 종목의 금액은 원화, 해외 종목의 금액은 달러로 표시한다.
- 국내 상장 해외지수 ETF는 국내 탭에, 미국 상장 ETF는 해외 탭에 표시한다.
- 해당 시장에 보유 종목이 없으면 짧은 안내와 종목 추가 버튼을 제공한다.

## 5. 보유 종목 표

PC와 모바일에서 동일한 컬럼 순서를 사용한다.

| 순서 | 컬럼 | 의미 및 표시 기준 |
| --- | --- | --- |
| 1 | 종목 | 종목명과 티커. 상세 정보 팝업 진입 제공 |
| 2 | 평가금액 | 해당 종목의 현재 총 평가금액 |
| 3 | 수량 | 보유 수량. 소수점 수량 지원 |
| 4 | 원금 | 해당 종목의 총 매수 원금 |
| 5 | 단가 | 평균 매수 단가. 현재가와 구분 |
| 6 | 수익률 | 해당 종목의 누적 수익률 |

### 구성 규칙

- 종목별 카드 배경·그림자·개별 테두리를 없애고 행 구분선으로 정리한다.
- 종목명은 왼쪽 정렬, 숫자 컬럼은 오른쪽 정렬한다.
- 숫자는 자릿수 비교가 쉽도록 일정한 숫자 폭을 사용한다.
- 행 높이는 PC 약 52~60px, 모바일 약 64~72px를 기준으로 실제 내용에 맞춰 조정한다.
- 긴 종목명은 최대 두 줄 또는 말줄임으로 표시하고 상세 팝업에서 전체 이름을 제공한다.
- 수익률은 양수 빨강, 음수 파랑, 0 또는 정보 없음은 중립색으로 표시한다.
- 전월 대비, 현재가, 수정 버튼은 종목 상세 팝업에 배치한다.
- 종목이 10개를 초과할 때만 10개 단위 페이지 이동을 표시한다.
- 탭과 조회 월을 변경하면 목록은 첫 페이지로 이동한다.

## 6. 모바일 가로 스크롤

화면 너비보다 표가 넓을 때 표 영역만 좌우로 이동한다. 페이지 전체에 가로 스크롤이 생기지 않도록 한다.

- 주요 컬럼을 숨기지 않고 여섯 컬럼 모두 유지한다.
- 종목명 열은 왼쪽에 고정한다.
- 손가락 드래그로 표를 좌우 이동할 수 있다.
- 표 아래에 스크롤바와 `좌우로 밀어 확인하세요` 안내를 제공한다.
- 좌우 이동 버튼을 제공해 버튼으로도 일정 구간씩 이동할 수 있도록 한다.
- 왼쪽 끝에서는 왼쪽 버튼, 오른쪽 끝에서는 오른쪽 버튼을 비활성화한다.
- 표가 화면에 모두 들어가면 이동 버튼과 스크롤 안내를 숨긴다.
- 종목명 고정 열이 금액을 가리지 않도록 고정 열의 너비와 구분선을 조정한다.
- 모바일에서 버튼 터치 영역을 확보하고, 키보드로도 스크롤 영역에 접근할 수 있도록 한다.

## 7. 도움말 및 종목 상세 팝업

### 계산 기준 도움말

상단 `[계산 기준 ⓘ]` 버튼으로 다음 내용을 확인한다.

- 환율 출처와 환율 적용 방식
- 총 누적 수익률 계산 기준
- 전월 비교와 `%p`의 의미
- 배당·세금·매수 당시 환율·환차손익의 반영 범위
- 지연 시세와 휴장일 가격 표시 방식

상세 설명은 기존 계산 로직과 일치하도록 작성한다.

### 종목 상세

종목명이나 행의 상세 진입 동작으로 다음 정보를 표시한다.

- 전체 종목명과 티커
- 보유 수량, 매수 원금, 평균 매수 단가
- 현재가와 평가금액
- 수익률과 전월 대비 변화
- 시세 기준 시각과 마지막 조회 시각
- 시세 갱신 상태
- 종목 수정 버튼. 과거 월 기록의 편집 제한은 유지

PC에서는 모달, 모바일에서는 하단 팝업으로 제공한다. 닫기 버튼, Escape 닫기, 포커스 복귀를 지원한다.

### 화면에 유지할 상태 정보

- 적용 환율과 기준 시각은 한 줄로 표시한다.
- 시세 갱신 성공 메시지는 잠시 표시한 뒤 사라진다.
- 환율 조회 실패, 저장된 시세 사용, 원금으로 임시 표시 중인 종목 등 금액 해석에 필요한 상태는 짧게 표시한다.
- 환율 오류에는 다시 조회 버튼을 제공하고, 상세 사유는 팝업에서 확인한다.
- 과거 월 조회 중임을 짧게 표시한다.

## 8. 디자인 기준

- 기존 블루 색상과 Pretendard를 유지한다.
- 선택한 탭과 주요 버튼에 블루 포인트를 적용한다.
- 평가금액을 가장 강조하고, 보조 설명의 시각적 비중을 줄인다.
- 본문은 14px, 보조 정보는 12px를 기본 기준으로 사용한다.
- 상단 제목·버튼과 조회 도구는 PC 기준 두 줄 안에 배치한다.
- 모바일에서는 조작 가능한 크기를 유지하며 필요한 경우 줄을 나눈다.
- 장식 아이콘과 불필요한 배너를 추가하지 않는다.

## 9. 구현 및 검증 순서

1. 통합 요약을 하나의 패널로 정리한다.
2. 국내·해외 탭과 시장별 요약 한 줄을 구성한다.
3. 기존 종목 카드를 여섯 컬럼의 표로 교체한다.
4. 모바일 고정 열, 가로 스크롤, 좌우 버튼을 적용한다.
5. 도움말과 종목 상세 팝업을 연결한다.
6. 목록 페이지 이동과 빈 상태·오류 상태를 정리한다.
7. 금액 계산 회귀 테스트와 PC·모바일 레이아웃을 검증한다.

- [x] 표에 종목·평가금액·수량·원금·평균 매수 단가·수익률이 순서대로 표시된다.
